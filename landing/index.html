install — pick your fighter

from zero to yoink in 2 mins

two ways in. docker does everything for you, node keeps it raw. both end with terminal yoinking. copy → paste → enjoyyy.

Node 20+ · ffmpeg · ~12 MB
method A · docker

the lazy way (recommended)

one command and the whole circus moves in: API + UI + stealth browser + VNC. batteries included.

clone it first (no way around this one)
# grab the repo, then start the machine git clone https://github.com/your/schlorp-machine.git cd schlorp-machine && docker compose up --build -d # → API + UI at http://localhost:6767
yoink from terminal (docker exec)
# container is named xdl — single or many docker exec xdl node scan-videos.js https://example.com/video-page # smol file pls docker exec xdl node scan-videos.js --max-quality 720 https://...
logs: docker logs -f xdl · VNC at :6778/vnc.html
method B · node

the hands-on way

raw & manual. clone it, npm it, start it. for tinkerers who like touching the worm directly.

install, all the way to npm start
# clone & install — that's it git clone https://github.com/your/schlorp-machine.git cd schlorp-machine && npm install # ffmpeg check (for HLS/DASH) ffmpeg -version | head -n 1 # start API + UI → http://localhost:6767 npm start
yoink from terminal (node)
# single or many — saves to ./media node scan-videos.js https://example.com/video-page # just print links, don't download node scan-videos.js --link-only https://...
files land in ./media — tidy.
